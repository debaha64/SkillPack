# SkillPack

`SkillPack` — набор переиспользуемых Agent Skills.

## Версия

0.0.1

## Skills

- [Simple First Skill](simple-first/) — применяй при выборе, предложении, проектировании, создании или изменении технического решения, структуры, артефакта, процесса либо новой ответственности, чтобы получить минимально достаточную форму без потери требований и обязательных свойств. Не применяй к обычным техническим ответам и объяснениям, если они не требуют такого выбора или создания решения.
- [Decision Interview Skill](decision-interview/) — используй, когда для корректного ближайшего результата нужно получить принадлежащее пользователю решение, существенное уточнение, требования или сведения, отсутствующие в доступном контексте, а также по прямой просьбе провести интервью. Задавай только необходимые вопросы; варианты предлагай, когда они уменьшают неопределённость, а рекомендацию — только при достаточных основаниях; ответы фиксируй кратко. Не используй для обычных информационных вопросов, перевода, общего стиля общения, подтверждения уже однозначно заданного действия или повторного запроса известных сведений.
- [Translate to Technical Russian Skill](translate-to-technical-russian/) — используй этот навык, когда пользователь прямо просит перевести выбранный материал на русский язык или из запроса однозначно следует, что он должен стать русским текстом в спокойном, плотном техническом стиле. Переводи любой выбранный материал полностью, сохраняя смысл, структуру, степень уверенности и защищённые технические фрагменты; перестраивай русский синтаксис естественно и без кальки. Не активируй навык только из-за наличия английского текста. Не используй его для объяснения, анализа, обсуждения, ответа или пересказа на русском языке, если пользователь не просит перевести выбранный материал, а также для локализации, сокращения или самостоятельного фактологического исследования.

## Использование

Каждый каталог является отдельным Agent Skill. Можно получить весь repository либо только нужный Skill. Конкретный механизм установки зависит от поддерживаемой Agent Skills среды.
