# SkillPack

`SkillPack` — набор Agent Skills для работы над техническими задачами.

## Версия

Версия пакета и всех трёх Skills — `0.0.2`.

## Состав

- [Simple First](simple-first/SKILL.md) помогает выбрать минимально достаточную форму технического решения без потери требований и обязательных свойств. Предпочитает пригодное существующее решение, затем штатный механизм и только при необходимости — новое. Если у предложенной пользователем формы есть существенно более простая пригодная альтернатива, указывает её и причинную разницу до реализации. Окончательный выбор остаётся пользователю; после явного подтверждения исходной формы работа продолжается без прежнего возражения, пока нет нового основания.
- [Decision Interview](decision-interview/SKILL.md) помогает получить необходимое решение, разрешение, уточнение или сведения от пользователя. Выбирает один вопрос, короткий пакет независимых решений или многошаговое интервью; фиксирует ответы и прекращает вопросы, когда данных достаточно для ближайшего результата. Рекомендации требуют оснований. Уже разрешённое действие не требует повторного подтверждения.
- [Translate to Technical Russian](translate-to-technical-russian/SKILL.md) отвечает за естественный и точный русский технический текст и перевод выбранного материала на русский при прямой просьбе или однозначно подразумеваемом переводе. При переводе сохраняет смысл, нормативную силу, структуру Markdown и защищённые технические фрагменты. Приложенный текст сам по себе не становится объектом перевода или редактуры.

Обычный технический вопрос не требует архитектурного разбора или интервью.

## Использование

1. Скачайте репозиторий целиком или каталог нужного Skill со всем его содержимым. Для Translate to Technical Russian сохраните подкаталог `references/` со словарём.
2. Подключите выбранные каталоги по инструкции вашей среды с поддержкой Agent Skills.
3. Задайте агенту задачу. Границы применения и правила каждого Skill описаны в его `SKILL.md`.

Skills можно подключать по отдельности или вместе. Способ установки и вызова определяется средой; само скачивание пакета не подключает Skills к агенту.
