# Терминология

| Исходный термин | Контекст или значение | Предпочтительный русский эквивалент | Допустимые варианты |
|---|---|---|---|
| `workflow` | организация или последовательность действий | рабочий процесс | порядок работы; последовательность действий |
| `runtime` | среда, в которой выполняется программа | среда выполнения | среда исполнения |
| `runtime` | продолжительность выполнения | время выполнения | длительность выполнения |
| `scope` | границы задачи, проекта или изменения | границы задачи | объём работы; область охвата |
| `scope` | область видимости имени в программе | область видимости | |
| `pipeline` | последовательность стадий обработки или доставки | конвейер обработки | цепочка обработки; цепочка доставки |
| `prompt` | запрос или инструкция, переданная языковой модели | запрос | инструкция |
| `prompt` | термин предметной области промптинга | промпт | запрос |
| `skill` | официальный объект стандарта Agent Skills | Skill | навык |
| `skill` | способность или умение | навык | умение |
| `retry` | повторное выполнение операции после неудачи | повторная попытка | повтор |
| `idempotent` | операция, повторное выполнение которой не меняет результат после первого успешного применения | идемпотентный | |
